# AI 畫平面圖：需求與繪圖規則模板

照原片「需求一次寫完整，要交代這 7 大項」的骨架（影片 52 秒截圖），每項填好再丟給 AI。
用在三種路線都行：Claude 電腦操作 AutoCAD、AutoCAD MCP、或叫 AI 寫 ezdxf 腳本（我們的做法）。

---

```
你是室內設計製圖員。請依下列條件產出可編輯的 AutoCAD 平面圖（DXF/DWG），
全部物件放在指定圖層，門窗與家具用圖塊（BLOCK）插入，不要炸開。
畫完自己核對：門窗數量 = 門窗表、各空間面積加總 = 合計，對不上就修正再交。

① 基本設定
- 單位：cm（INSUNITS=5）；出圖比例 1:100
- 樓高：___ cm；外牆厚 15、內牆厚 12（RC 外牆 / 1/2B 磚內牆）
- 字型：微軟正黑體 msjh.ttc；字高 1:100 出圖 2–2.5 mm（模型 20–25）

② 格局（尺寸、房間配置）
- 軸線 X：1=0, 2=___, 3=___ …；Y：A=0, B=___ …（牆中心線）
- 空間：主臥 ___×___、臥室二 ___×___、主浴 ___、公浴 ___、客廳、餐廳、廚房、走道
- 哪些邊是開放（不砌牆）：___
- 柱：___×___，位置 ___

③ 編號規則
- 柱 C1、C2…（由左下往右、再往上）
- 門 D1（大門）、D2（房門 90×210）、D3（浴室門 75×210）、SD1（拉門）
- 窗 W1、W2…（同尺寸同編號）

④ 圖面表現（配色、線型、門窗符號）
- 圖層：S-GRID 軸線(紅, CENTER) / S-COLS 柱(實心填滿) / A-WALL 牆 / A-PATT 牆填充 ANSI31 /
  A-DOOR 門 / A-GLAZ 窗 / A-FURN 家具 / A-ANNO-DIMS 尺寸 / A-ANNO-TEXT 文字 / A-ANNO-TABL 表格 / A-AREA 面積邊界(不出圖)
- 門：門扇 + 90° 開門弧，標明開向；窗：牆厚內 4 條線
- 出圖：白底黑線，線寬牆 0.5、其他 0.13–0.25

⑤ 繪圖順序
軸線 → 柱 → 牆（挖門窗洞）→ 窗 → 門 → 家具 → 房名＋面積 → 尺寸 → 四表 → 面積計算 → 門窗圖

⑥ 數量表
- 門窗表：編號、名稱、寬、高、窗台高、數量（數量從圖上圖塊數出來，不要手填）
- 柱表、牆表（中心線長度）
- 面積計算表：每間「淨面積（扣牆柱，不扣門窗）」，列算式、m²、坪（1 坪 = 3.305785 m²）

⑦ 門窗圖
- 每個編號一張立面：寬×高、窗台高，1:50

交付：DXF（或 DWG）+ PDF + 核對紀錄（門窗數量、面積加總）。
不確定的尺寸先列出來問我，不要自己猜。
```

## 小提醒（原片作者的話，影片字卡）
- 「大方向要交代，小細節也不能省」：原片截圖可以看到作者連「柱子黃色填滿、外框紅色」「備註多一條樓高 360CM」「面積計算表不扣門窗」都寫進指令。
- 「畫出來還是要核對」：尺寸、位置、數量、計算方式都要回頭對需求。我們用 `verify.py` 自動對。
