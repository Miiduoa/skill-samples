# 交接包：AI 畫 CAD 平面圖（門窗表＋面積表＋門窗圖）

給：變現執行　｜　來源：IG @mk.thinktank（M.K. 澄跡智庫）reel DeYpFJGxARy　｜　2026-10-29

## 這個技能在做什麼
把「丈量尺寸／手繪草圖／建商平面圖」交給 AI，產出**可在 AutoCAD 直接修改**的平面圖：
分層（軸線、柱、牆、門、窗、家具、尺寸、文字、填充）、門窗與家具是真圖塊、有尺寸標註、
房名＋面積、門窗表、柱表、牆表、面積計算表、門窗立面圖，再加 PDF。
我們不用 AutoCAD（要付費），用 Python ezdxf（MIT、免費）直接寫 DXF，AutoCAD 打得開、可存成 DWG。
每張圖都跑 `verify.py` 自動核對：門窗數量＝門窗表、各房面積加總＝合計、淨面積＋牆柱＝外包絡。

樣本：`dl22_plan.dxf`、`plan_color.png`（v2 彩色，深色底模擬 AutoCAD 模型空間）、`plan.png`／`plan.pdf`（白底黑線），
原創虛構「斗六 22 坪三房兩廳」。對照圖：`compare_v2.jpg`（v2，原片左、我們右）、`compare.jpg`（v1 黑白版，留存）。

## 照做步驟（每步一行）
1. 跟客戶拿：丈量尺寸圖或建商圖、現場照片、門窗尺寸、牆厚、樓高。
2. 把尺寸填進 `PROMPT.md` 的 7 大項；缺的尺寸先列出來問客戶。
3. 複製 `make_plan.py`，只改 GX/GY 軸線、WALLS、COLS、OPENINGS、ROOMS、FURN、LABEL_AT（可叫 AI 照 PROMPT.md 改）。
4. 執行 `.venv/bin/python make_plan.py`，產出 DXF。
5. 執行 `.venv/bin/python verify.py 檔名.dxf`，全部 PASS 才往下做。
6. 執行 `.venv/bin/python render.py 檔名.dxf plan.png`（白底，同時出 PDF），再執行 `render.py 檔名.dxf plan_color.png --dark` 出彩色版；打開 PNG 看有沒有字壓到線、門撞到家具。
   要做算量表時，先跟客戶確認樓高、天花高、壁磚高，以及哪些窗要做窗簾盒（填進 `make_plan.py` 的 H_FLOOR／H_CEIL／H_TILE、CURTAIN_ROOMS）。
7. 交件：DXF＋PDF＋核對紀錄。客戶要 DWG 時，用 ODA File Converter 轉（免費，在這台還**沒測過**）。
8. 註明「示意／代繪，不是簽證圖」。

## 還不夠好的地方（v2 跟原片比）
- 原片的門表、窗表分開，而且有「型式」欄；我們合成一張門窗表。
- 原片的案子比較長，有車庫、12 支柱、20 cm 外牆；我們是 6 支柱、15 cm 外牆的小公寓，所以整體看起來比較「方」。
- 原片是 AutoCAD 的 SHX 字型，畫面比較細；我們用 Noto 粗體出圖。DXF 裡的字型設的是 msjh.ttc，Mac 版 AutoCAD 可能要換字型。
- 門窗立面只有外框、分割線和把手點，原片的門扇有斜線和格子。家具都是簡化線框。
- 公浴的房名有一點壓到門弧線（字小，看得清楚）。
- 窗簾盒照原片用 m 計，不換算坪。
- DXF 沒有在真的 AutoCAD 開過（這台沒有 AutoCAD），ezdxf audit 0 錯誤。轉 DWG 也還沒測。
